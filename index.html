Vector File Converter

Companion tool for the Spectral Indices Explorer Google Earth Engine app. Select a vector file from your computer and get GeoJSON text that is ready to paste into the app. Geometry and attributes are kept as in the source file (no clip, no dissolve). Files are processed in your browser and are never uploaded to a server.

1. Select a file

Drag and drop a file here, or click to browse Supported: .zip (complete shapefile), .geojson / .json, .gpkg (GeoPackage), or a set of .shp + .dbf + .prj files
For shapefiles, include the .prj file so coordinates are converted to WGS84 automatically. Without a .prj, the data is assumed to be in WGS84.

2. Options

Defaults keep the original shape and all attributes: 7 decimals is about 1 cm and tolerance 0 means no simplification. Only lower the precision or raise the tolerance if the output is too large to paste (for large polygons try 0.0001, about 10 m, which changes the shape slightly).

4. Paste into the app

  1. Return to the Spectral Indices Explorer app.
  2. In the Upload ROI / Alert panel, paste the GeoJSON into the text box.
  3. Click Load Alert Polygon (ROI). The app uses Polygon / MultiPolygon features as the ROI.
  4. Click a polygon on the map to open the alert popup (attributes, area, before / after imagery). For before / after imagery, the file needs a date attribute in YYYY-MM-DD format.
